Review: backup of the index

⚠ This writes a new file with patient data on the node

Instance {{.I.Name}} (node ID {{orDash .I.Remembered.NodeID}}, AE title {{orDash .I.Remembered.AETitle}}) makes a snapshot of its index while it keeps running.

  • The file goes into the node's own backup directory {{.B.Directory}}, under a name LibreDCM makes. No file is replaced.
  • LibreDCM checks the free space first (the index size plus 10 %) and starts nothing when it is short.
  • The backup holds the index only. Images are not included: back up the image store separately.
  • The file holds patient data: protect the directory.
  • One backup runs at a time. It may take several minutes on a large index. DICOM services keep running.
