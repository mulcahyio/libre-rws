Licence actions (administrators)

Each button first shows a warning page. Nothing is sent to LibreDCM before you approve it there with a reason. Every action is recorded in the audit logs of Libre WT and LibreDCM. A licence key is never written to either log: only its last four characters.

Acknowledge the unlicensed notice

Records that you have seen the notice. It lifts the block on configuration reloads for 24 hours, as LibreDCM -license-ack NAME on the host does. It is recorded under your user name.

Install a licence file

LibreDCM checks the file (signature, product, this machine, dates). A file it refuses changes nothing: the installed licence stays.

Activate online

The node sends the key to the licence server and installs the licence it returns. Nothing changes when the server refuses or can't be reached.

Activation request file (offline)

For a node without internet access: download a request file, send it to the licence portal, then install the licence file it returns. The file holds the key in encoded form; keep it like the key.
