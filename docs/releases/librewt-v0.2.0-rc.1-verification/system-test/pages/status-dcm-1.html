Start, stop and restart

Libre WT does not start, stop or restart LibreDCM. Do this on the host of the node: with the installer script (LibreDCM.ps1 restart on Windows, ./libredcm.sh restart on macOS and Linux; see "Day-to-day" in the LibreDCM install guide, deploy/workstation/INSTALL.md) or with Docker (docker compose restart in the install folder). Settings that need a restart are changed in the node's configuration on the host.
